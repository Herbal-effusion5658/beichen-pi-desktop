## 🔍 Troubleshooting Tips

### The app won't open
- Make sure you've downloaded the full file (check file size on the website).
- Try right-clicking the file and selecting "Run as administrator."
- Restart your computer and try again.

### I don't see any models available
- Make sure you have a local AI tool installed (like Ollama or LM Studio).
- Check that the tool is running in the background.
- Restart beichen-pi-desktop after starting your AI tool.

### The app is slow
- Close other programs to free up memory.
- Try a smaller, faster AI model.
- Check if your computer meets the minimum requirements.

### I can't find my downloaded file
- Press `Ctrl + J` in your browser to open downloads.
- Check the "Downloads" folder in File Explorer.
- If you used a different browser, look in its download history.
